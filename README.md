# Sample 03 — KORVEXA 기업형

Danny Web Studio 포트폴리오용 가상 엔터프라이즈 기술기업 사이트입니다.

## Branding
- Brand: KORVEXA
- Descriptor: Enterprise Systems
- Tagline: MOVE COMPLEXITY FORWARD.
- Palette: Graphite / Electric Lime / Cyan / Off-white
- 실제 회사가 아닌 포트폴리오용 가상 브랜딩입니다.

## Reference direction
기업 서비스 사이트의 일반적인 구조를 참고했습니다:
- Samsung SDS: AI/Data, Cloud, Business Solution 중심의 명확한 사업 구조
- LG CNS: AX, Cloud, Smart Factory/Logistics, Consulting 등 엔터프라이즈 서비스 포트폴리오
- IBM Consulting: AI/Data, Cloud, Consulting과 비즈니스 성과 중심 설명
- Accenture: Capability, Industry, Case Study, Careers를 연결하는 기업 정보 구조

특정 사이트를 복제하지 않고 정보구조와 B2B 커뮤니케이션 패턴만 참고해 새 브랜딩으로 설계했습니다.
